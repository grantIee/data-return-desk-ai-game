API Documentation

Build an agent that plays as you. Your agent uses your session ID (shown above) so decisions count toward your score on the Hall of Fame. Base URL: http://localhost:8888

How It Works

Start a run through the UI, then hand your session ID to your agent and let it play for you.

  1. Start your run — enter your name in the lobby
  2. Copy your session ID from the bar above
  3. Give it to your agent — it calls the API using your session
  4. Agent loop: GET /api/session/{your_id}/next → download files → analyze → POST /api/session/{your_id}/decide
  5. Your score updates on the Hall of Fame in real time

Agent Loop Endpoints

GET/api/session/{your_session_id}/next
Get the next customer and download URLs for the 3 files.
# Response: { "customer_id": "CUST-0042", "number": 5, "files": { "receipt": "/api/files/CUST-0042/receipt.pdf", "transactions": "/api/files/CUST-0042/transactions.xlsx", "fraud_report": "/api/files/CUST-0042/fraud_report.pptx" } }
POST/api/session/{your_session_id}/decide
Submit your decision. Body: {"customer_id": "CUST-0042", "decision": "ACCEPT"}
Decision must be "ACCEPT" or "DENY".
Returns: {"correct": true, "explanation": "Rule 2: ..."}

File Endpoints (download & analyze these)

GET/api/files/{customer_id}/receipt.pdf
Receipt PDF — check if a customer photo is present (Rule 1).
GET/api/files/{customer_id}/transactions.xlsx
Transaction history — calculate return rate and dollar ratio (Rules 3-4). No summary row.
GET/api/files/{customer_id}/fraud_report.pptx
Fraud report deck — the assessment is buried on one slide among filler (Rule 2).

Helper Endpoints

GET/api/session/{your_session_id}
Check your current score, accuracy, and avg time.
GET/api/rules
Decision rules as text — feed this to your agent so it knows the logic.
GET/api/leaderboard
Hall of Fame rankings. Score = correct × (100 / avg_seconds).
GET/api/time
App defaults, or pass ?session_id=... for per-session countdown and state.

Example — Full Agent Loop

Copy your session ID from above and paste it as SID below.

BASE="http://localhost:8888" SID="paste-your-session-id-here" # Loop: get customer → download files → decide while true; do NEXT=$(curl -s $BASE/api/session/$SID/next) CID=$(echo $NEXT | jq -r .customer_id) # Download the 3 files curl -s $BASE/api/files/$CID/receipt.pdf -o receipt.pdf curl -s $BASE/api/files/$CID/transactions.xlsx -o tx.xlsx curl -s $BASE/api/files/$CID/fraud_report.pptx -o fraud.pptx # TODO: Analyze files and determine ACCEPT or DENY # - receipt.pdf: is there a customer photo? # - tx.xlsx: calculate return_rate and dollar_ratio # - fraud.pptx: find the assessment slide # - Apply rules 1-5 in order DECISION="ACCEPT" # or "DENY" curl -s -X POST $BASE/api/session/$SID/decide \ -H "Content-Type: application/json" \ -d "{\"customer_id\":\"$CID\",\"decision\":\"$DECISION\"}" done
